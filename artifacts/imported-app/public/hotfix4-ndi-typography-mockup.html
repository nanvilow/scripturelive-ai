v0.7.194-hotfix.4 — Disconnect NDI Typography from app Typography panel

Operator changes app-wide Font Size on Output → Large (or Text Alignment, Text Shadow, Font Family) and the NDI Typography panel's "Mirror Live" dropdown label updates accordingly — so it looks like body settings just bled into the NDI Lower Third. The actual NDI feed Wirecast receives is already isolated (route.ts uses hardcoded NDI defaults when fields are undefined), but the misleading "Mirror Live" UI promise was the source of every "NDI is following Live again" report. Fix: remove the inherit option entirely, label the panel as fully independent, and make the dropdowns show the concrete NDI default (sans / xl / on / center) when the operator hasn't customized them.

BEFORE — current NDI Typography panel

Every dropdown offers a "Mirror Live (X)" option as the default. The label updates the moment the operator changes the app-wide Typography panel — so it looks like the body settings just changed the NDI feed. They didn't (route.ts falls back to hardcoded NDI defaults), but the UI promise of "Mirror Live" is a lie.

STEP 3. NDI Lower Third in Wirecast looks identical before/after. No interference.
