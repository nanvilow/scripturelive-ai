v0.7.194-hotfix.4 — Reference Alignment finally applies in-app

Operator picks Reference Alignment → Left in Typography & Appearance. The setting writes to settings.referenceTextAlign correctly and the renderer reads it correctly — but the rendered <div class="slide-reference" style="text-align:left"> shrinks to content width because its flex-column parent (.slide-content) has align-items: center, which centers it as a block. text-align: left on a content-width element is a no-op. Same shape bug in slide-renderer.tsx for the main Live Display panel.
