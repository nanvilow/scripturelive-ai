v0.7.194-hotfix.4 — NDI Background opaque/transparent toggle

Today the NDI feed is always sent alpha-keyed (transparent) — designed for vMix/OBS chroma-key compositing. Wirecast (and any operator who isn't keying) ends up with text floating on whatever's behind, because there's no background fill in the NDI frame. Fix: new Background setting under FULL SCREEN. Default Themed (opaque — matches what the in-app preview shows). Lower-Third stays alpha-keyed.

BEFORE — what Wirecast shows today (broken)

NDI capture surface strips html/body backgrounds → BGRA alpha=0 on every background pixel → Wirecast composites over its canvas → operator sees floating text with only a thin border, no themed fill.

New control in NDI Output panel (under FULL SCREEN)

NDI Display Mode
Affects the NDI feed only. Your secondary screen stays on its own mode.
Background
Themed sends a fully painted frame — Wirecast, Resolume, vMix/OBS without keying all show the themed dark card exactly like the in-app preview.
Transparent sends an alpha-keyed matte (just the text + frame on a clear background). Pick this only if your switcher composites NDI over its own program (vMix/OBS chroma-key workflows).

Why this happens (architecture)

In-app NDI Live Preview (image 1, what operator sees):
/api/output/congregation?ndi=1 — no transparent=1 → CSS strip at route.ts L316 is skipped → solid theme renders → preview is opaque ✓

Actual NDI capture (image 2, what Wirecast receives):
ndi-output-panel.tsx L304 + L399 hardcodes transparent: true → main.ts L2254 forwards ?transparent=1 → route.ts L316 strips html/body/stage/output background → FrameCapture BrowserWindow paints with backgroundColor: '#00000000' → image.getBitmap() returns BGRA with alpha=0 on every theme pixel → NDI frame is alpha-keyed → Wirecast composites the see-through frame over its canvas. ✗

Fix: new ndiFullScreenBackground setting controls whether to pass transparent: true when in FULL SCREEN mode. Lower-third stays transparent as today (the bar is meant to overlay program output).
