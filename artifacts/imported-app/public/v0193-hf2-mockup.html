What changed: the three shared store fields (mediaPaused, mediaCurrentTime, mediaLoop) were split into previewMediaPaused / liveMediaPaused, previewMediaCurrentTime / liveMediaCurrentTime, previewMediaLoop / liveMediaLoop. The Preview transport reads/writes only the preview* trio; the Live transport only the live* trio.

External feeds (NDI / OBS / secondary screen): these always show the LIVE pane to the congregation, so they follow the live* trio — unchanged behaviour from the operator's point of view.

Go-Live handoff: still smooth — when you send a media slide to Live, the live deck seeds itself with the preview pane's current frame and auto-plays from there. Preview keeps ticking on its own (so you can still scrub it) but is muted to prevent echo.
