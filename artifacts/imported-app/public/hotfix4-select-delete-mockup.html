How it behaves
  • Default off — opening the panel looks exactly like today. Just a new small "Select" button at the right side of the tab header.
  • While Select is ON — single/double-click does NOT preview or go-live. Rows toggle their checkbox instead. This protects Live from accidental clicks during cleanup.
  • Tabs still switch — clicking History/Queue keeps Select mode on but clears the current selection (since each tab has its own list).
  • Cancel exits selection mode without deleting. Delete (N) removes the chosen rows and auto-exits selection mode. The currently-live verse is unaffected even if it was sent from a deleted History row — Live keeps showing it.
  • Disabled state — if a tab is empty, the Select button is greyed out.
