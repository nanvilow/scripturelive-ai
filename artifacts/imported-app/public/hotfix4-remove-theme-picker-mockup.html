v0.7.194-hotfix.4 — Hide Congregation Screen Theme picker

Operator wants the 6-button theme picker (Minimal / Worship / Sermon / Easter / Christmas / Praise) gone from the Display & Output settings. We delete the UI block but keep settings.congregationScreenTheme in the store at its default 'minimal' — so every consumer (output-payload, broadcaster, logos-shell, easyworship-shell, library-compact, slide-renderer, panel presets) keeps working without modification. Operators with a persisted custom theme keep their persisted value too.

Why it's safe: The picker was just one of several writers to settings.congregationScreenTheme. The Panel preset cards in this same settings view (Sermon Mode / Minimal Stage / Worship Set) still write theme values via their preset apply handlers (L2411/2422/2433). Operators who want to change theme can keep using those presets; everyone else gets the safe 'minimal' default. Zero risk to rendering — every consumer reads from the store, not the picker.
Net change: 1 file (settings.tsx), ~21 lines deleted (the Separator + the theme picker block). Zero changes to the store, broadcaster, route renderer, or any of the 15+ consumer call sites. The picker disappears; theme rendering keeps working with whatever value is already persisted.
