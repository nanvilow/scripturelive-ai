# ScriptureLive AI — Architecture decisions archive

Guard-rails for releases older than v0.7.230. Full release text lives in `artifacts/imported-app/CHANGELOG.md`; this file keeps only the one-line invariants extracted from `replit.md` during rolling-window upkeep. v0.7.230 and newer stay in `replit.md` until they're rolled out in turn.

## Older releases (one-line guard-rails)

-   **v0.7.229 — Standby-poster click-side predicate widening + per-clip mediaFit on standby poster (shipped inside v0.7.230)**: TWO sites in `library-compact.tsx` + `logos-shell.tsx` L3810 MUST keep the URL-tail regex `/\.(mp4|webm|mov|m4v|mkv|ogv)(\?|#|$)/i` in lockstep with the render-side gate at `logos-shell.tsx` L1197 (v0.7.222 Fix #8). Adding a new extension to one site WITHOUT updating all THREE re-opens the dual-decoder contention bug. Standby poster per-clip fit now flows through the v0.7.230 `resolveMediaFit` helper — see v0.7.230 entry in `replit.md` for the 4-surface lockstep.
-   **v0.7.228 — Output/NDI startup-delay preheat via `setPreheatVid`**: `output-payload.ts` MUST emit `preheatMediaUrl` only when `pinnedPreviewSlide` is a media-video AND its `mediaUrl !== cur.mediaUrl`. `congregation/route.ts` `setPreheatVid` MUST use `preload="auto"`, kick `play().then(pause)` in `loadeddata` (NOT `loadedmetadata`), `setTimeout(pause, 0)` in `play` listener. `#preheatLayer` MUST stay off-screen (left/top:-99999px, opacity:0, pointer-events:none) so compositor skips the layer. URL dedup via `__preheatUrl` module-local MUST come BEFORE teardown loop.
-   **v0.7.227 — `bgBrightness` CSS-var system + freezeBg standby-poster `<video>`**: `--bg-opacity` / `--bg-scrim` driven by `settings.bgBrightness`, mapping `scrim=(1-opacity)*0.333`, slider `min={10}`. Var fallback baseline `.85`/`.05` (v0.7.226 visual baseline). Freeze-bg poster `<video>` MUST keep `preload="auto"` (NOT `'metadata'`/`'none'`), no autoplay, no loop, `muted`, `playsInline`, `loadeddata→play().then(pause).catch(pause)`, `play→setTimeout(pause,0)`. WCAG-AA legibility at low brightness depends on `.slide-text` `text-shadow` stack. v0.7.230 extended `--bg-opacity` to foreground media (fallback `1`); pair invariant + lockstep now spans 4 selectors not 3.
-   **v0.7.226 — Operator brightness pick `.85 / .05`**: var fallback baseline (3 pair-bound selectors). Pair invariant: opacity + scrim alpha move together on the same surface. v0.7.227 enforces by source (single slider drives all). WCAG-AA legibility at `.85/.05` depends on `.slide-text` `text-shadow` stack — do NOT remove the shadow at this brightness.
-   **v0.7.225 — freezeBg first-frame paint**: `route.ts` setBgVid branch MUST use `v.preload='auto'` (NOT `'metadata'`/`'none'`), MUST kick `v.play().then(pause).catch(pause)` in `loadeddata`, MUST `setTimeout(pause, 0)` in `play` listener (NOT synchronous), AND MUST NOT call synchronous `v.pause()` after `layer.appendChild(v)`. Re-used by v0.7.227 standby poster AND v0.7.228 `setPreheatVid`.
-   **v0.7.224 — goLive resume seek**: `logos-shell.tsx` + `easyworship-shell.tsx` goLive pinned-path MUST call `setLiveAuto(pinned)` BEFORE `setLiveMediaCurrentTime(resumeFrom)` (atomic reset in setLiveAuto would clobber otherwise). `MediaVideoSurface` play-effect `canplay` handler MUST re-apply pending seek from `useAppStore.getState()` directly (NOT closed-over `mediaCurrentTime`) before `play()`.
-   **v0.7.223 — NDI opaque + BGRX FourCC**: `main.ts` `wantTransparent` AND URL-param branch BOTH MUST be `opts.transparent === true` (NOT `!== false`). `ndi-service.ts` `nativeSendFrame` MUST pick `senderTransparent ? FOURCC_BGRA : FOURCC_BGRX`; opaque path MUST force `slot[i] = 0xff` at i=3,7,11,... for old-receiver BGRA fallback. `stop()` MUST reset `senderTransparent = false`. v0.7.230 added `forceBgraForObs` override path — see v0.7.230 entry in `replit.md`.
-   **v0.7.222 — Single-click STANDBY gate (5-condition AND gate)**: `logos-shell.tsx` `previewStandbyForLive` MUST stay intact. URL-tail regex fallback for legacy persisted slides (mediaKind missing) MUST stay in `liveIsMediaVideo` upstream — and now ALSO in BOTH click-side handlers per v0.7.229 lockstep (3 sites total). Predicate widening in render-side without click-side widening is silently broken.
-   **v0.7.220 — NDI async send + buffer pool**: `ndi-service.ts` hot path MUST use `send_send_video_async_v2` NOT sync v2, `clock_video:false`, 2-slot `videoBufferPool` with `(i+1)%2` advance. `armBridge` setInterval MUST be `Math.max(16, Math.floor(1000/fps))`. `lingerStop`/`gracefulStop` fade loops MUST `await setTimeout(frameMs)` between sends.
-   **v0.7.219 — MediaPreheat link tag**: warm-up MUST use `<link rel="preload" as="video" crossOrigin="anonymous">` in `document.head` (NOT hidden `<video preload="auto">` — silently allocates HW decoder slots). Warm-up URL set MUST union `pinnedPreviewSlide` + `liveSlide` direct refs alongside `slides[]`. `crossOrigin` MUST match eventual `<video crossOrigin="anonymous">`. v0.7.228 added a SECOND preheat path inside the output renderer (`setPreheatVid` — see v0.7.228 entry).
-   **v0.7.217 — SSE writeback throttle**: `MediaVideoSurface` live-surface `writeThreshold` MUST be `0.50`, preview MUST stay `0.25`. 4 unconditional transport listeners (play/pause/seeked/loadedmetadata) MUST register + cleanup. `congregation/route.ts` receiver drift tolerance MUST be `1.5` with `!IS_NDI` exemption intact.
-   **v0.7.216 — autoPlay gate + canplay retry**: `MediaVideoSurface` `<video>` `autoPlay` MUST be `!mediaPaused && surface === 'preview'`. `library-compact.tsx` `sendMediaToPreview` MUST flip `setPreviewMediaPaused(true) + setPreviewMediaCurrentTime(0)` BEFORE `pinPreviewSlide` when live plays different media-video. Play/pause effect MUST register one-shot `canplay` retry `{once:true}` + cleanup. Radix portals MUST use `z-[60]` never bare `z-50`. LiveDisplayCard volume MUST flip `setLiveBroadcastAudio` AND live `<video>` `muted` MUST OR-in `!liveBroadcastAudio`.
-   **v0.7.215 — Per-pane Clear buttons**: `clearLive` MUST call `clearLiveAuto()` BEFORE the 4-primitive sequence. PreviewCard "Clear Preview" MUST call ONLY `clearPinnedPreview() + setPreviewSlideIndex(-1)` (independence — MUST NOT touch live primitives).
-   **v0.7.214 — Voice/AI targets LIVE only**: every voice handler in `speech-provider.tsx` MUST read live anchor via `s.liveSlide ?? (liveIdx >= 0 ? slides[liveIdx] : null)` AND commit via `setLiveAuto(slide) + setLiveActiveVerseIndex(0)`. Voice dispatcher MUST contain ZERO `setPreviewSlideIndex(` outside `bible_says`. MUST NOT use `addScheduleItemQuiet` as fallback.
-   **v0.7.213 — setSlides clears pin**: `store.ts` `setSlides` reducer set() payload MUST include BOTH `liveSlide: null` AND `pinnedPreviewSlide: null`. Pattern: any "hard-reset" reducer taking ownership of Preview MUST clear pin + AI ref.
