MASTER INSTRUCTION (BIBLE VERSE DETECTION SYSTEM)

You are enhancing the Live Transcription feature with a Bible verse detection system (Bible-only references).

The goal is to detect spoken scripture in real-time, including:

Full verses
Partial phrases
Common preacher-style expressions
1. DETECTION RULES

The system must:

Match text without case sensitivity (uppercase/lowercase should not matter)
Ignore punctuation (commas, periods, apostrophes, etc.)
Detect partial phrases, not only full verses
Allow fuzzy matching (to handle speech errors or transcription mistakes)
Work in real-time during live transcription
2. OUTPUT FORMAT (IN WORDS)

When a scripture is detected, the system should return:

The phrase that was detected
The Bible reference (Book, Chapter, Verse)
Optionally, the full verse text

Example (in words):

Detected phrase: “Jesus wept”
Reference: John chapter 11 verse 35

4. HOW THE SYSTEM SHOULD WORK (IN WORDS)
The system listens to live transcription text
It compares spoken words against stored Bible phrases
It checks for:
Exact matches
Partial matches
Similar phrases (fuzzy matching)
If similarity is high enough (about 80%):
It detects a scripture
When detected:
It highlights the phrase
It shows the Bible reference
It creates a new paragraph (as you requested earlier)
5. IMPORTANT PERFORMANCE RULES

To make this work smoothly:

Detection must be fast (real-time)
Avoid repeated detection of the same verse
Allow multiple verses in one transcript
Do not interrupt transcription flow
6. OPTIONAL ENHANCEMENTS (HIGHLY RECOMMENDED)
Highlight scripture text live
Show verse on second screen
Group verses into paragraphs
Add sound/visual alert when scripture is detected
🔥 FINAL NOTE

For best performance in churches and live preaching:

Use hundreds (500–1000) phrases
Include:
Short phrases (3–5 words)
